# TypeScript Exercises Repository

This repository contains a collection of TypeScript modules focused on software architecture, strict typing, and clean code principles.

## 📁 Project Structure

- **[module-1](./module-1)**: Statistical Analysis Utility.
  - Implementation of core mathematical functions (`average`, `median`, `outliers`).
  - Strict null handling and environment configuration.
- **[module-2](./module-2)**: University Management System (Architecture).
  - Domain-Driven Design (DDD) with Entities and Interfaces.
  - Advanced types: Discriminated Unions and Generics.
  - Simulated Asynchronous API client with standardized responses.

## 🛠️ Tech Stack & Tools

- **Language**: [TypeScript](https://typescriptlang.org) (Strict Mode)
- **Runtime**: [Node.js](https://nodejs.org)
- **Execution**: [tsx](https://github.com) (Fast TypeScript execution)
- **Compiler**: Built-in `tsc`

## 🚀 How to Use

Each module is autonomous. To run any exercise:

1. Navigate to the module folder: `cd module-X`
2. Install dependencies: `npm install`
3. Run in development mode: `npm run dev`
